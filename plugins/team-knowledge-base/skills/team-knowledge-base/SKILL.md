# 团队文档库

## 连接要求

- 只能连接 `https://cheniplaw.com.cn/kb-mcp/mcp`。
- OAuth 权限只能是 `kb.read`，不得要求或配置 Bearer Token。
- 登录时只引导用户在小O协作授权页面输入自己的成员姓名和密码。
- 不得读取、记录、复述或输出密码、授权码、访问令牌或刷新令牌。
- 如果 `xiaooTeamDocs` 不可用，不得改用名称相似的数据源或直接访问 Git。

## 允许的工具

- `kb_list_directory`
- `kb_search_files`
- `kb_read_document`

不得调用或声称具备上传、覆盖、删除、移动、重命名、写入或权限修改能力。

## 工作流程

1. 将“团队文档库”“团队知识库”“团队资料”等自然语言请求映射到 `xiaooTeamDocs`。
2. 先用最小必要的目录或搜索查询定位候选文档。
3. 只读取完成请求所必需的文档。
4. 区分文档事实与推断，并尽可能标明文件名或文档路径。
5. 权限过滤后没有结果时，说明“当前成员权限范围内未找到”，不得推断整个团队库不存在该文档。

## 安全边界

- 始终只读并尊重服务端成员权限、租户隔离和文档 ACL。
- 不访问 Git 历史、其他分支、已删除内容、部署密钥或服务端配置。
- 用户要求写入、删除、覆盖、移动或权限变更时，说明插件不支持并停止。
